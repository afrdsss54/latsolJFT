- Unified interactive queue for due/weak items: search, filter due/weak and ready/all stages, pagination, direct navigation, refresh. No new review date invented for sources without one. Source-specific weakness indicator and separate latest chapter-exam error counts.

- Daily planner with saved 15/30/45/60-minute budget, ranked recommendations and last launched target. No claim that user spent the estimated minutes or completed a task merely by opening it.
- Strict explicit unit prerequisites + stage gating; chapter prerequisite is advisory priority (explained in UI). New direct open methods for Kana, old mastery flashcards, Listening, and S8.4.2 mode selection; return from M6/M7 to V3 when opened from V3.
- New Unified Storage record `latsoljft-learning-s92m8:<enc(profile)>`; adapter unchanged. No migration or conversion of existing mastery into new evidence. Separate legacy Smart Learning (CBT-derived), planner and gamification retained. Full storage inventory and scope decisions in `S9.2-M8-PROGRESS-AUDIT.md`.
- Gap matrix: fixed Gap numeric values (all 0 for unit-count target), scope status and explicit remaining quality gaps. No new curriculum content in M8.

## Known limitations / follow-up M9
- Browser environment failed even blank page; test desktop and mobile Safari, keyboard focus, actual audio/TTS, refresh, cache upgrade and offline manually before release. No independent visual or accessibility certification.
- Legacy Smart Learning question-derived review and old Study Planner are deliberately outside the M8 queue; no universal cross-source SRS or semantic deduplication. Separate source counts prevent a misleading global mastery total.
- Planner estimates time and regenerates from current evidence; does not track actual elapsed time, daily completion or calendar notifications. Resume stores last target opened via M8, not question index or every navigation path. Most legacy pages return to their original home/BAB rather than M8; re-enter via navigation. M6/M7 have direct return.
- Source schemas may not record attempts or failures completely (notably S8.4.2); no inferred missing data. Latest-exam weaknesses persist until another exam even after remedial; old mastery thresholds vary. Unknown or malformed inner backup records and concurrent multi-tab writes remain existing storage limitations.
- Direct routes and UI handlers have only static/simulated verification, not a real browser. No external linguistic review, formal Minna/Irodori competency equivalence, independent exam expansion, or new content claim.
