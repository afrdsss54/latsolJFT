# S4.0 Curriculum Source Mapping Audit

## Scope and source honesty
Based on the S3 application source, its 100 legacy Academy module records, S0 competency matrix, and a **provisional** topic-level outline of Minna no Nihongo I/II. No publisher textbook files or official Irodori chapter contents were supplied or inspected for this checkpoint. The Irodori mapping therefore contains **54 empty lesson-level slots** (18 per volume) and broad book-level themes only; it does not invent chapter names or precise can-do statements. Minna lesson-to-topic assignments are planning hypotheses requiring edition-specific verification. No copyrighted book dialogue, exercise, or page is reproduced.

## Audit numbers
- 100 legacy modules preserved in mapping; F0=3, F1=19, F2=21, F3=46, F4=11, F5=0.
- 23 existing competency IDs preserved.
- 50 Minna topic-level planning entries (Shokyu I: 1–25; II: 26–50).
- 54 Irodori placeholder entries (Starter, Elementary 1, Elementary 2; 18 per book), deliberately unverified.
- Seven-step unit schema: goal → kotoba → bunpou → listening → active practice → speaking → mastery/review.

## Key gaps
1. **Critical:** F0 has only 3 mapped legacy modules, insufficient for complete kana and pronunciation foundations.
2. **Critical:** Listening needs verified original scripts and real audio; existing text-only examples do not demonstrate listening mastery.
3. **High:** One quiz item per Academy module is insufficient for mastery claims.
4. **High:** Grammar sequencing, prerequisites, verb conjugation and particle contrasts need editorial review and more examples.
5. **High:** Speaking roleplays and feedback need authored scenarios and privacy-safe browser fallbacks.
6. **High:** F5 has no mapped Academy module and needs competency-linked bridge units.
7. **High:** Irodori lesson titles and can-do objectives require primary-source verification before publishing mappings.

## Design decisions
- Both learning paths share module IDs and progress; this milestone adds **only planning files**.
- No changes to app.js, questions.js/json, lessons.js/json, localStorage keys, or service worker.
- Reference IDs never imply permission to copy source text. Write original Indonesian explanations, Japanese examples and questions; license-check any third-party assets.
- `candidateMinnaRefs` are heuristic matches only; blank means unmapped, not absent from a book.
- F0–F5 are internal instructional stages, not CEFR certification or official JFT level equivalences.
