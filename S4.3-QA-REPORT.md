# S4.3 QA Report — Listening Content Lab

## Scope
Based on S4.2 checkpoint ZIP. 22 F0–F2 units linked one-to-one with 22 listening entries. Each entry provides a comprehension multiple-choice task and a kana/kanji dictation task (44 tasks total), original or adapted from LatSol-authored S4.1–S4.2 content. Some earlier one-line source utterances were extended to two-line practice dialogues. No Minna no Nihongo/Irodori book text was copied or claimed verified.

## Implementation
- `curriculum/listening-lab.json` and `.js`: 22 listening entries, source unit IDs, stage, dialogue, comprehension, dictation, feedback and contextual meaning hint.
- `listening-lab-engine.js`: scoring, whitespace/punctuation-tolerant Japanese dictation, per-profile isolated localStorage key `latsoljft-jls-s43-listening-`, attempt log, completion on one correct result for each task type.
- `listening-lab-ui.js`: dashboard, F0–F2 filters, TTS Japanese 0.75/1/1.25 speed in study mode, stop control, answer gating, transcript revealed after checking a task, explanations, return to matching seven-step unit.
- `learning-path-ui.js` and `seven-step-ui.js`: entry points and deep-link navigation.
- `index.html`, `sw.js`: new assets and S4.3 cache version.

## Limitations / known issues
- Browser end-to-end and actual Japanese TTS playback have not been verified; voice availability varies by browser and OS.
- The UI shows a contextual Indonesian meaning hint and Japanese transcript, **not a full line-by-line translation of every utterance**.
- Dialogues and explanations require independent Japanese editorial review.
- No native recorded audio, pronunciation scoring, or listening difficulty calibration yet.
- Dictation uses exact written match after normalization; semantically equivalent alternate spellings may not be accepted.
- Learning mode has unlimited TTS plays. CBT code and CBT audio rules are unchanged, not browser-E2E verified.
- New listening completion indicates both task types were answered correctly at least once, not robust delayed mastery.
- Production-stable status is NOT claimed.
