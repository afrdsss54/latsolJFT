## Deployment acceptance (manual)

1. Simpan baseline S9.6 untuk rollback; backup Unified Storage dan ekspor riwayat CBT terpisah. Jangan hapus localStorage.
2. Extract ZIP; upload isi pada root repository; deploy preview Vercel (jangan pasang kembali workflow GitHub Pages).
3. Desktop: pilih profil, masuk Jalur Belajar, cek dashboard vs jalur, buka/tutup sidebar, BAB 01–14, lab dan ujian baru/lama, review, audit serta CBT.
4. Mobile 320–430px: cek lima tombol bawah, safe-area, tidak menutup konten, overflow horizontal, tombol kembali, tabel dan keyboard Jepang; ulang di Safari iPhone.
5. Uji sesi CBT dan ujian BAB penuh, timer, kembali, skor, refresh, TTS, switching profil, restore dan cache offline/update. Verifikasi navigasi baru tidak muncul saat sesi aktif.
6. Gunakan Tab/Shift+Tab/Enter, skip link dan pembaca layar; cek fokus, heading, landmark, kontras. Jangan rilis Production Stable sebelum acceptance lulus.
