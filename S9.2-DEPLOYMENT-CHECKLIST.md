# S9.2 Mega Final — Deployment checklist (Vercel)

**Status: all items below are pending manual acceptance unless explicitly marked.** Use a preview deployment first. Keep the original M8 ZIP and Git commit for rollback.

## Before updating
- [ ] On the existing production domain, use Unified Learning → Backup semua profil; save the JSON offline. This backup excludes CBT history, active exams and gamification. Export CBT history separately from its History screen (export is not a full restore mechanism). Do not update in the middle of an exam.
- [ ] Do not clear browser site data/localStorage. A preview domain has separate storage; use test profiles or a sanitized backup there. Avoid putting private backups in GitHub.
- [ ] Unzip the complete archive, upload contents at repository root, not the enclosing folder. Remove old `.github/workflows/deploy.yml` from GitHub if still present; archive omission does not delete remote files.
- [ ] Vercel: static site/no framework, root directory containing index.html, no build command necessary. Review diff and keep previous deployment available.
- [ ] Verify preview status Ready, HTTPS, index, all JS/CSS requests return expected files (not HTML error pages), and developer console has no errors.

## Desktop / mobile acceptance
- [ ] Chrome/Edge on Windows: create two test profiles, switch, ensure each progress stays isolated.
- [ ] iPhone Safari and Android Chrome: 320–430px widths, portrait and landscape; check no page-wide horizontal overflow, readable Japanese, touch controls, scrollable tables, keyboard focus, reduced motion, zoom, skip link.
- [ ] Check sidebar, dashboard, chapters 01–14 and back routes; open at least one unit from every BAB, all seven steps, Academy, Kana, legacy flashcards, M6 Kotoba and Kanji, all five M7 skills, old Listening/Speaking, chapter exam, PR and remedial.
- [ ] Test Japanese TTS with installed ja-JP voice at each speed, no-voice fallback, listening transcript hidden before answering, dictation, audio cancellation, speaking confirmation (no pronunciation score).
- [ ] Adaptive V3: 15/30/45/60 minute planner, due/weak filters, search/pagination, prerequisite block, direct links, resume, V2 fallback; check dashboard counts against individual modules.
- [ ] Test correct and wrong answers, mastery streak, review due, profile switching, refresh persistence. Confirm existing mastery IDs remain, even if chapter completion percentages changed due to expanded curriculum.
- [ ] With test data: migrate legacy records twice, export backup, restore, reject invalid/unsafe backup, check other profile and CBT unchanged for invalid restore. Valid restore replaces matching records (including shared maps); use backup of all profiles.
- [ ] CBT: complete a full session, timer, navigation, section boundaries, audio, submit, history, resume after refresh, report. Compare against M8; do not claim official JFT score equivalence.
- [ ] Service Worker: verify new cache `latsoljft-content-jls-s92m9-1` installed; online reload then offline reload at root/index; verify declared JS/CSS work, unknown URLs not cached. Test TTS offline separately (not guaranteed). Verify refresh after upgrade and rollback to prior version.
- [ ] Check that no external paid dependency is required. Record issues with browser/version, page, steps, expected/actual, console log and screenshot. Do not share private backup data.

## Promote / rollback
- [ ] Only promote after acceptance passes; browser/linguistic review remain open in this checkpoint. Test against production origin without deleting site data. If broken, roll back Vercel deployment/commit to M8 and reload online; restore progress only if necessary from saved backup. Do not uninstall/clear storage as a first step.
- [ ] Independent Japanese language review and official curriculum alignment sign-off are separate from software acceptance. Document any unresolved defects before release.
